# Kirti Vishwakarma — AI & Generative AI Engineer Portfolio

Personal portfolio website for Kirti Vishwakarma, an AI and Generative AI Engineer specializing in RAG architectures, LLM systems, and end-to-end machine learning pipelines.

## Tech Stack

- **Framework**: TanStack Start (React 19)
- **Styling**: Tailwind CSS v4
- **Language**: TypeScript
- **Icons**: Lucide React

## Development

```sh
npm install
npm run dev
```

## Production Build & Deployment

To build locally:

```sh
npm run build
```

### Deploying to Vercel

1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) and click **Add New... > Project**.
3. Import the GitHub repository `kirtivish974/portfolio`.
4. Vercel automatically detects TanStack Start / Nitro settings.
5. Click **Deploy**.
